# Projeto Algoritmos de Grafos

Este projeto foi desenvolvido como parte das atividades acadêmicas para a disciplina de Estrutura de Dados. O objetivo é implementar uma estrutura de Grafos em Java, manipulando Vértices e Arestas.

## 🛠️ Tecnologias Utilizadas
* Java (Versão 17 ou superior)

## 📁 Estrutura do Projeto
* `Vertice.java`: Representação dos nós do grafo.
* `Aresta.java`: Representação das conexões e pesos entre os vértices.
* `Grafo.java`: Lógica de inserção, busca e manipulação do grafo.
* `Main.java`: Ponto de entrada para execução e testes dos algoritmos.

## 🚀 Como rodar o projeto
1. Clone o repositório
2. Abra o projeto na sua IDE de preferência (ex: IntelliJ IDEA)
3. Execute a classe `Main.java`
